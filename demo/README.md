# Live Interactive Mockup

`index.html` is a self-contained, interactive front-end mockup of the workspace overview screen — the same screen shown as the hero image in the main [README](../README.md#see-it-in-action). It's hosted live via GitHub Pages at:

**https://ttmathew.github.io/Lectify-Analytics/demo/**

This is a clickable UI prototype, not the real product — there's no backend behind it, and any interactions are limited to what the mockup itself implements (view switching, hover states, etc.). It exists so a visitor can get a feel for the interface beyond a static screenshot.

The company name and peer tickers were anonymized to Company X / CO-Y / CO-Z / CO-W to match the convention used everywhere else in this repo — do not reintroduce real company/ticker names here.

To update this mockup, replace `index.html` with a new export (keeping the same filename so the live URL and the README link don't need to change), then re-apply the same anonymization if the new export reintroduces a real company/ticker name.
